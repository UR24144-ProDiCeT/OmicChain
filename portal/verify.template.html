OmicChain fingerprint verification

Check that an analysis fingerprint was published on the blockchain, and when.

Advanced

The public Base endpoints are rate-limited. You may use your own node or provider, but this page trusts whatever that endpoint answers.

What this page checks — and what it does not

It confirms that this exact fingerprint was published to the OmicChain proof contract, at which block and time, and by which address.

  • It does not check the analysis files themselves. To verify them, use the RO-Crate that accompanies the certificate and run python omicchain_core.py verify <folder> --expected <fingerprint>.
  • It does not tell you who the publisher is: an address is not an identity.
  • The contract only records that a fingerprint existed at that time; it makes no claim about whether the analysis is scientifically sound.
